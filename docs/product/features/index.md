# 浏览

* [图库](gallery.md) - 公开照片与个人照片的瀑布流，按城市、多层级标签、色调筛选
* [照片详情](photo-detail.md) - 大图、笔记、拍摄点小地图、器材参数、同地点照片
* [地点页](places.md) - 一个地点的所有照片、匹配半径、拍摄朝向和附近地点；创建者和管理员可以编辑
* [地图](map.md) - 照片按省、市、区县、地点合成图集，随缩放合并或拆开，轮播并显示数量
* [索引](index-page.md) - 标签树和按城市排列的地点
* [Living 模式](living-mode.md) - 全屏轮播，可按标签、主题、地点或"那年今日"取图
