# Living 知识包

Living 是一个旅行与生活的影像图库：上传照片，自动匹配地点，用多层级标签整理，为每张照片写笔记，把照片编成主题和游记，在地图上回看，用 Living 模式全屏轮播。这里按 [Open Knowledge Format](https://github.com/GoogleCloudPlatform/knowledge-catalog/tree/main/okf) v0.2 组织：每个文件只讲一个概念，frontmatter 里的 `type` 说明它是什么，概念之间用 Markdown 链接相连。
