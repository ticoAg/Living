# 内容

- MapLibre 底图（OpenFreeMap 矢量瓦片，重新配色为纸面陆地、淡蓝水面、安静的道路）。
- 有可见照片的地点显示为圆形计数标记加地点名；选中的标记反色。
- 地点多了标记会叠在一起，所以相邻的地点合并成聚合标记：同样的圆点，数字是其中的照片总数，外加一圈细线与单个地点区分。点击聚合标记放大到它散开的程度（每次至少放大一级），放大到够近，才显示带名称的单个地点标记。
- 顶部筛选：季节（春夏秋冬）、光与天气（晨光 日落 蓝调 夜 雾 雨 雪）。筛选后标记计数随之变化，为 0 的变淡。
- 城市切换：按照片所在城市快速定位。
- 侧栏：地点名（宋体加宽字距）、类别、坐标、照片数、缩略图网格、"打开地点"和 Living（只播放这里的照片）。

# 聚合

- 用 MapLibre 数据源自带的聚合（`cluster: true`，在 Worker 线程里算），标记仍是 HTML 元素，样式沿用 `.map-pt-dot`。`MapView` 的 `cluster` 属性默认关闭，只有地图页打开；照片页、地点页和游记里的小地图不聚合，表现不变。
- 相邻约 80 像素以内的地点合并（缩放不是整数时屏幕上在 80 到 160 像素之间），放大到第 17 级起不再合并。
- 聚合上的数字是各地点当前照片数之和，所以屏幕上所有数字加起来等于可见的照片总数。聚合里所有地点在当前筛选下都是 0 张时，聚合显示 0 并变淡。
- 选中的地点在聚合里时，这个聚合反色；顺着反色的聚合一路点进去就能找到它。选中不会移动地图。
- 只为视野内（外加一圈余量）的聚合和地点建标记，平移和缩放时按地点和位置复用已有的标记，不整批重建；筛选和选中只更新文字与状态。
- 聚合按钮至少 44px 见方，键盘可达，读屏器念"N 个地点，M 张，放大查看"；点击后焦点落在新出现的标记上。

# 规则

- 只统计访客可见、位置未隐藏的照片。
- 初始视野包含全部标记；地址栏记录选中地点（`?poi=<id>`）。
- 筛选和选中都不会移动地图；只有点聚合标记（放大）和切换城市会改变视野。
- `MapView` 在前端共享模块中的位置见 [前端分区](/architecture/frontend.md)。
