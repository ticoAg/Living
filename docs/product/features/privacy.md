# 公开范围

| 值 | 照片 | 主题 |
|---|---|---|
| `public` | 出现在图库、地图、索引、Living | 出现在主题列表 |
| `unlisted` | 只能通过链接访问 | 只能通过链接访问 |
| `private` | 只有本人 | 只有本人 |

新照片默认 `public`，新主题默认 `private`。

# 位置精度（对他人生效）

| 值 | 坐标 | 朝向 | 地点 | 区县 |
|---|---|---|---|---|
| `exact` | 原值 | 显示 | 显示 | 显示 |
| `fuzzy` | 四舍五入到约 500 米 | 隐藏 | 显示 | 显示 |
| `hidden` | 隐藏 | 隐藏 | 隐藏 | 隐藏 |

城市始终显示。本人永远看到原值。

# 隐私区域

在设置里添加（名称、中心、半径，默认 300 米）。落在区域内的照片上传时强制设为 `hidden`，匹配接口返回区域名，上传页显示"在隐私区域「家」内"。

# 文件

- 原图存放在 R2 的 `o/` 前缀下，只有本人能下载。
- 公开展示的三种尺寸由浏览器重新编码，不含 EXIF。
- 私密照片的尺寸图也只对本人返回。
