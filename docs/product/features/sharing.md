# 用户故事

- 旅行回来，合集「西湖两日」还是仅自己可见，里面不少照片也是。想给家人看，又不想公开：在合集页点「分享」，新建一个 30 天内有效的链接，发给家人。家人点开就能看整本游记。
- 一条写给朋友的记录，只想给她一个人看：分享这条记录，链接发过去。她看完后，在设置的「分享链接」里删掉它，链接立刻打不开。
- 学书法的项目想给老师看进度：分享项目，老师能看到每次的练习和阶段总结，不用注册。

# 规则

- **谁能建**：作者为自己的记录、合集或项目建；在阅读页（记录页底部、合集页和项目页顶部）点「分享」。一项可以有几个链接，分别给不同的人，各自删除互不影响。
- **有效期**：1 天、7 天（默认）、30 天或不过期，从新建时算起。过期的链接留在列表里，标「已过期」，打不开，可以删掉。
- **删除**：删掉立刻失效，已经打开的页面刷新后也打不开。删掉的链接不能恢复，要再给人看就新建一个（地址不同）。
- **管理**：分享对话框列出这一项的链接；[设置](/product/features/accounts.md) 的「分享链接」列出全部，标明每个链接打开的是什么。
- **打开**：链接是 `/s/<24 位随机字符>`。打开后跳到这一项平常的地址（`/e/:id`、`/t/:id`、`/projects/:id`），这个浏览器从此能看到它，直到链接失效；从这一页点进去的记录和照片也能打开。
- 记录要已完成，链接才打得开：草稿不行，归档后暂时打不开，取消归档后恢复。对话框里会说明。
- 上限：一项 20 个、一个人 500 个链接。

# 能看到什么

| 分享的是 | 打开的人能看到 |
|---|---|
| 记录 | 这条记录和它的全部照片 |
| 合集 | 这个合集、封面和照片条目，以及其中已完成的记录和这些记录的照片 |
| 项目 | 这个项目、里程碑，以及其中已完成的记录和这些记录的照片 |

不管这些内容各自的公开范围（仅自己可见的也能看到），但仍然：

- 看不到草稿和已归档的记录，看不到原图。
- 位置照常按 [位置精度](/product/features/privacy.md#位置精度对他人生效) 处理：隐藏位置的照片仍然不显示位置。
- 只看得到这一项和其中的内容：作者的主页、图库、地图和其他记录不会因此多出任何东西。
- 把 `/e/:id` 这样的平常地址转给别人没用：对方没有打开过分享链接，照常按公开范围处理。

# 隐私

- 链接本身就是钥匙：拿到地址的人都能打开，转发也一样。要收回就删掉。
- 链接只在作者手里：别人看不到某一项有没有分享链接、有几个。
- 删除记录、合集或项目时，它的链接一并删除。
- 通过链接读到的内容不进浏览器和中间服务器的缓存。
