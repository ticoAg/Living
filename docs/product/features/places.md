# 内容

- 地点名按地图注记的方式大字号加宽字距排版；类别符号、城市与区县、坐标。
- 统计：照片数、时间跨度、匹配半径。
- 地图：地点中心、匹配半径虚线圈、每张照片的拍摄点和朝向扇形。
- 筛选：时段（晨 昼 暮 夜）、季节（春夏秋冬）；不在结果里的拍摄点变淡。
- 照片瀑布流，每张下方是标题和日期。
- 附近地点（5 公里内、有可见照片），按距离排序。
- Living：只播放这个地点的照片。

# 规则

- 多位用户在同一地点拍的公开照片都会出现，标注拍摄者。
- 本人或管理员可以修改地点名、类别和匹配半径。
