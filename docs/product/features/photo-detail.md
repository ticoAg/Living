# 内容

- 大图放在浅灰"卡纸"上，按原比例完整显示。
- 标题（没有就用地点名）、拍摄日期与时间、时区。
- [照片笔记](/product/features/photo-notes.md) 全文。
- 地点：类别符号 + 地点名（链接到 [地点页](/product/features/places.md)）、到地点的距离、坐标（WGS-84）、镜头朝向。
- 拍摄点小地图：照片位置、朝向扇形、地点位置和两者之间的虚线。
- 器材：相机、镜头、焦距（含等效焦距）、光圈、快门、ISO。
- 标签：完整路径可见（如 题材 / 自然 / 湖），点击回到筛选后的图库。
- 同地点的其他照片缩略条，可直接切换。
- 所属主题列表。
- 操作：Living（从这张开始播放）；本人可见"编辑"。

# 规则

- 他人的照片按 [隐私](/product/features/privacy.md) 规则处理坐标：模糊时不显示朝向、精确坐标和到地点的距离，隐藏时不显示地点和地图。
- 键盘左右键切换上一张、下一张（在当前列表内）。
