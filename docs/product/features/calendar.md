# 用户故事

- 想知道上个月哪几天什么都没记：打开日历，空着的日子一眼就看到；点一天，补记那天的事。
- 某天拍了照片又写了记录：那天的格子里铺着一张照片，底下几个点是几条记录，点开在旁边看全部。
- 年底想回头看这一年：打开 2026 的回顾，写了多少、拍了多少、哪几个月最勤、最常去哪里，都在一页上。

# 日历

地址 `/archive/calendar`，档案的第二个标签页（时间线、日历、项目）。只有登录后可用，只显示自己的内容；草稿算，已归档的不算，和时间线一样。

- **一个月**：周一在前。地址里 `?month=YYYY-MM` 选月份，默认这个月；`?day=YYYY-MM-DD` 选一天，这个月默认是今天，别的月份默认是那个月最后一个有内容的日子。换月份、换日子不增加浏览历史。
- **每一天**：有照片的铺一张照片，那天拍的收藏照片优先，其次是那天第一条带照片的记录的第一张，再次是那天拍的第一张；有记录的在底部画点，一条一个，最多三个。今天的日期是蓝色的，选中的一天有一圈框。
- 月份下面一行是这个月有内容的天数、记录数和照片数；年份是链接，打开这一年的回顾。
- **选中的一天**在旁边（手机上在下面），排法和时间线相同：记录和照片按时间倒序，已经放进记录的照片不再单独出现；什么都没有时写「这一天没有内容」。旁边的「补记」（今天和以后是「记一笔」）打开编辑器，新记录就在那一天：以前的日子只有日期、不带时刻，今天的带此刻的时刻。
- **键盘**：Tab 进到选中的那天，方向键左右换一天、上下换一周，越过月初月末时一起翻到上个月、下个月。
- 每次只读这个月的记录和照片（[记录](/api/entries.md#get-apientries)、[照片](/api/photos.md#get-apiphotos) 列表的 `from`、`to`），不受时间线各 5000 条的上限影响，多早的月份都是完整的。

# 年度回顾

地址 `/archive/<年份>`，从日历的年份或时间线里每年的标题进入，日历标签页保持选中。上面列出所有有内容的年份，可以切换。

- **数字**：记录、照片、有内容的天数、最长连续几天、去过几个地点、写了多少字（标题和正文的字数）。过万的写成「1.2万」。
- **每一天**：十二个小月历，每天按那天的记录和照片的总数从浅到深上色。按倍数分级而不是按差值：一年里最多的一天最深，只有一项的最浅，所以一天几百张照片不会把只记了一两笔的日子都压成最浅；每天都只有一项时都画最深。指向或聚焦一天显示「5月2日：2 条记录 · 2 张照片」，点一天打开日历的那一天，点月份打开那个月；还没到的日子只画框。
- **收藏**：这一年拍的收藏照片，按拍摄时间，最多 24 张。
- **项目**：这一年写过记录的项目，或者有里程碑在这一年的，带这一年的记录数、天数和里程碑；记录多的在前。
- **合集**：日期和这一年有交集的合集；没有日期的算在建立的那一年。
- **地点**、**标签**：这一年的照片和记录用得最多的各 10 个；点标签打开按这个标签筛选的时间线。
- **类型**：每种记录写了几条；只有一种时不显示。
- 这一年什么都没有时说明，并给出日历的入口。
- 数字由 [回顾接口](/api/review.md) 在服务器上算好，同样不受时间线的上限影响。
