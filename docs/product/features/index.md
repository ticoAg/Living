# 记录

* [记录](entries.md) - 一段文字和一个发生时间，按需加标题、照片、附件、标签和类型；默认仅自己可见，边写边保存
* [附件](attachments.md) - 记录里的视频、录音和其他文件：录音、上传、播放和下载，跟着记录的公开范围
* [今天](today.md) - 随手记、今天的记录与照片、草稿、往年今天
* [档案](archive.md) - 记录与照片按天排成一条时间线，按类型、标签筛选，按年份跳转
* [日历与年度回顾](calendar.md) - 一个月一张表，选一天看全部、补记空着的日子；一年一页的回顾
* [项目](projects.md) - 一个持续的过程：放进相关的记录，用里程碑分出阶段，看最初和最近的作品
* [作品与文章](showcase.md) - 个人主页最先展示作品和文章，各有一页列出全部；访客视角看自己的页面在别人眼里的样子
* [搜索](search.md) - 在自己的档案里找字：记录、照片、项目、合集、地点和标签

# 浏览

* [图库](gallery.md) - 公开照片与个人照片的瀑布流，按城市、多层级标签、色调筛选；切到记录看公开的记录
* [照片详情](photo-detail.md) - 大图、笔记、拍摄点小地图、器材参数、同地点照片
* [地点页](places.md) - 一个地点的所有照片、匹配半径、拍摄朝向和附近地点；创建者和管理员可以编辑
* [地图](map.md) - 照片按省、市、区县、地点合成图集，随缩放合并或拆开，轮播并显示数量
* [索引](index-page.md) - 标签树和按城市排列的地点
* [Living 模式](living-mode.md) - 全屏轮播，可按标签、合集、记录、地点或"那年今日"取图
* [媒体库](library.md) - 自己的照片、视频、音频和文件：各有多少多大，哪些不在记录里，选几样写成一条记录

# 照片与整理

* [上传与整理](upload.md) - 批量上传、读取 EXIF、生成多尺寸图、发布
* [地点匹配](poi-matching.md) - 根据 GPS 和镜头朝向自动匹配地点
* [多层级标签](hierarchical-tags.md) - 预置标签树加用户自定义标签
* [照片笔记](photo-notes.md) - 为每张照片写一段文字
* [合集](themes.md) - 把照片和记录编成旅程或专题
* [游记](travelogue.md) - 合集的阅读视图，按天展开照片、记录和笔记

# 账号与安全

* [账号](accounts.md) - 邀请码注册、登录、个人主页
* [隐私](privacy.md) - 可见性、位置精度和隐私区域
* [分享链接](sharing.md) - 把一条记录、一个合集或一个项目交给想给看的人，可随时删除，可设有效期
* [导出](export.md) - 把整个档案带走：Markdown、living.json 和照片原文件，zip 或导出到文件夹
* [导入](import.md) - 把导出带回来：选文件夹或全部 zip，已经在的跳过、不覆盖，链接换到这个站点
* [站点管理](admin.md) - 邀请码与注册方式
