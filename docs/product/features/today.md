# 用户故事

- 午休时打开，写一句「试了新买的狼毫，出锋好控制多了」，按记下，接着干活。
- 晚上打开，看到今天的两条随记和下午拍的三张照片。
- 上周写了一半的读书笔记还在「草稿」里，点进去接着写。
- 翻到「往年今天」：三年前的今天在西湖边，那天拍了十几张照片。

# 规则

- 只有登录后可用；未登录时引导登录。登录和注册后默认来到这里。
- 顶部是随手记的输入框，见 [记录](/product/features/entries.md#写)；麦克风按钮录音，录好的和文字一起记下，见 [附件](/product/features/attachments.md#随手记)。
- **进行中**：已经开始的进行中 [项目](/product/features/projects.md)，各带「记一笔」；今天记过的打勾。
- **今天**：发生在今天的已完成记录，以及今天拍的、还没放进当天记录里的照片。按作者设备的本地日期判断。
- **草稿**：所有草稿，最近改过的在前，不限日期。
- **往年今天**：往年同月同日发生的已完成记录和拍的照片，按年份倒序，标出是几年前。
- 已归档的记录不出现在这里。
- 都没有时只显示输入框。
