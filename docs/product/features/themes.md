# 两种主题

- **旅程**：有起止日期，照片按时间排列，自动按天分段，游记里画出路线。例："2026 秋 · 杭州三日"。
- **专题**：不受时间约束的精选，例："西湖四季""城市里的桥"。

# 创建

- 从空白开始，或从图库当前筛选、某个地点、一段日期范围的照片创建。
- 旅程：选定日期范围后，自动带入这段时间自己的照片，并在每天第一张前插入"第 N 天"分段。
- 上传时也可以直接把新照片加入已有主题。

# 编辑

- 标题、副标题、导语（纯文本段落）、封面照片、起止日期、公开范围（公开 / 仅链接可见 / 仅自己）。
- 条目三种：照片（可写本主题内的说明，覆盖照片笔记）、文字段落、日期分段。
- 拖动或用上下按钮调整顺序；从自己的照片里添加；移除条目不会删除照片。
- 首次设为公开时记录发布时间。

# 列表

- `/themes`：所有公开主题，按更新时间倒序；`?mine=1` 显示自己的全部主题。
- 个人主页列出该用户的公开主题。
