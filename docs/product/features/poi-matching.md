# 候选来源

1. 站内已有地点（D1 `pois`），优先级最高。别人自建的地点只有在被公开且显示位置的照片用过之后才会出现，见 [pois 的隐私](/data/pois.md#隐私)。
2. 配置了高德 Web 服务 Key 且照片在中国境内时用高德周边搜索；否则用 OpenStreetMap 的免费公共服务 Photon，列出半径内带名称的地点：景点、桥、公园，也包括店铺、餐馆、酒店和有名字的建筑。Photon 不可用时退到 Overpass。高德使用 GCJ-02 坐标，查询前把照片的 WGS-84 坐标转换过去，结果再转回 WGS-84。
3. 逆地理编码得到省、城市和区县：高德 regeo，或 OpenStreetMap Nominatim（街道级地址里没有地级市时再问一次，见 [地点接口](/api/pois.md#post-apipoismatch-登录)）。上传时一并写进照片，[地图](/product/features/map.md) 据此按省、市、区县合成图集。
4. 外部结果缓存在 KV 7 天，同一位置不重复请求。
5. 候选先显示最近的 12 个，其余点"显示全部"展开。
6. 列表里没有想要的，在"搜索附近的地点"输入名称或其中几个字：只在照片周围约 6 千米内找，按距离排序，见 [地点接口](/api/pois.md#get-apipoissearchqlatlng登录)。没有坐标的照片则不限范围。

# 排序

- 分数 = 距离（米）− 25（候选在镜头朝向 ±30° 内）− 10（站内已有地点）。分数小的在前。
- 面状地点（湖、公园、街区）若照片在其范围内，距离记为 0，排在点状地点之后作为兜底。
- 匹配半径默认 300 米，可在 30–1000 米之间调整；超出半径的候选显示但不可选。

# 自动与确认

- 第一名距离 ≤ 25 米且在朝向内，或距离 ≤ 15 米：自动匹配（`poi_method = auto`）。
- 否则标记"待确认"，用户选择后记为 `confirmed`。
- 按时间推断得到的记为 `inferred`；手动搜索或新建的记为 `manual`。
- 选中外部候选时在 D1 新建地点（按 `source + source_id` 去重）；默认匹配半径按类别取值（桥 60 米、寺 150 米、山 400 米、湖 600 米……）。

# 界面

上传页和照片编辑页的匹配地图：真实地图上标出拍摄位置、当前匹配半径虚线圈和镜头朝向扇形，候选按列表里的排名编号标在各自的位置上。点编号即选中该地点，列表同步勾选，选中的地点在地图上显示名称；超出匹配半径的候选变淡，不能点。选中不会移动地图，改半径时重新缩放到新的半径圈。浏览器不支持 WebGL 2 时，退回原来的示意图：50 / 100 / 200 / 300 米同心圆，候选按方位和距离标出。
