# 内容

- 标签：每个根一组，按层级缩进；字号随包含的照片数增大；色调标签显示色块；点击进入筛选后的图库。
- 地点：按城市分组，城市名用宋体，每行"类别符号 地点名 …… 数量"，点击进入地点页；末尾一行"位置未公开 N"。
- 顶部汇总：照片数、标签数、地点数。照片超过 5000 张时，汇总后面加一项「只显示最近的 5000 张」，数量都只算这 5000 张，见 [照片接口](/api/photos.md#get-apiphotos)。

# 规则

- 只统计访客可见的照片；数量为包含子孙标签后的总数。
