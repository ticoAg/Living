# 用户故事

- 练完一首曲子，在「今天」的随手记里点麦克风录下来，写一句「第三小节还是赶」，按记下。
- 把旅行时拍的一段湖边的视频放进那天的记录，写一句说明，读的人点开就能看。
- 读书笔记附上一份 PDF 讲义，阅读页里点名字就在浏览器里打开。
- 一段很长的视频在地铁里传断了，到站后点「重试」，从断的地方接着传。

# 添加

- 编辑器里照片的下面是「附件」：「录音」直接录，「添加」选文件，一次可以选几个。
- 视频和声音能在页面里放，其他文件（文档、表格、压缩包……）下载后打开。图片请放进照片：照片有尺寸图、位置和标签，附件没有。
- 一条记录最多 20 个附件，一个最多 2 GB；空文件加不了。
- 每个附件可以写一句说明、调整顺序、移除。移除的附件离开这条记录，七天后删去。
- 选好就开始上传，一个接一个，显示进度。断网、服务器忙时自动重试几次；还不行就停下，「重试」从断的那一片接着传，「取消」丢掉它。
- 上传之前，浏览器读出视频的时长和尺寸，截一帧作封面；声音读出时长。读不出也照样能传。
- 上传中「完成」按不了，底部写着「附件上传中…」，关闭或刷新页面前浏览器会先问一句。正文照常自动保存。
- 只有附件、没有文字和照片的记录也能保存。

# 录音

- 编辑器的「录音」和随手记的麦克风：开始后显示「录音中」和时长；「停止」后录好的立刻上传，「取消」什么也不留。
- 格式是浏览器能录的第一种：WebM（Opus），录不了时 MP4（AAC）或 Ogg。文件名是开始的时间，如「录音 2026-11-19 08.30.webm」。
- 要先允许网站使用麦克风。没有许可、找不到麦克风、麦克风被别的程序占着时，分别说明；不能录音的浏览器不显示录音按钮。

# 随手记

- [今天](/product/features/today.md) 的随手记可以录几段音，录好的排在输入框下面，各标着时长。
- 「记下」时录音和文字一起成为一条记录，只有录音也行。
- 还没记下的录音记在这台设备上，刷新也在；七天内没记下的会被清理。
- 「写长文」把文字和录音一起带进编辑器。

# 阅读

- 阅读页里，附件排在照片下面：视频带封面，点开就放；声音是一个播放条；其他文件是名字、大小和下载按钮，PDF 点名字在新页面打开。
- 每个附件都能下载，文件名是上传时的名字。
- 浏览器放不了的格式写着「这个浏览器放不了，可以下载后打开」。
- 列表里的记录卡片显示最多三个附件：视频的封面，或声音、文件的图标和时长，多的写「+n」。
- 个人主页的作品没有照片时，用视频的封面作封面。

# 位置

手机拍的视频和语音备忘录（MP4、MOV、M4A）常在文件里写着拍摄地点。上传前，浏览器在文件里找到这几处，原地抹成空白：只改这几个字节，长度不变，视频的其余部分原样不动，上传的就是抹过的文件。

其他格式的视频和声音、其他文件按原样上传，里面的信息（比如文档的作者）照原样保留。

# 隐私

- 附件没有自己的公开范围，跟着所在的记录：能打开这条记录的人就能播放、下载它的附件，凭 [分享链接](/product/features/sharing.md) 打开记录的人也一样。编辑器的公开范围下面写着「附件随记录」。
- 还没放进记录的、从记录里去掉的附件，只有自己能读到。
- 文件不进任何缓存：记录改为仅自己可见后，别人马上就读不到。公开记录里视频的封面在别人的浏览器里最多留一小时。
- 上传的网页、SVG 这类文件只能下载，不会在这个站点上打开、运行。

# 导出与导入

- [导出](/product/features/export.md) 勾选「包含照片原文件和附件」时，附件的文件和视频的封面放在 `media/` 下，Markdown 里是指向它们的链接；不勾选时，Markdown 里写着附件的文件名。
- [导入](/product/features/import.md) 把附件的文件重新上传，放回原来的记录。
