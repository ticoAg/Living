# 预置标签树

由迁移 `migrations/0002_preset_tags.sql` 写入，`owner_id` 为空，所有人可见：

- 题材：自然（湖 山 海 河 树 花）、城市（街头 建筑 夜景）、人文（桥 塔 寺 展馆）、生活（室内 美食 茶 人 宠物）
- 光与天气：光线（晨光 白昼 日落 蓝调 夜）、天气（雾 雨 雪）
- 季节：春 夏 秋 冬
- 色调：暖 冷 绿 蓝 黑白（带颜色，显示为色块）

# 自定义

- 用户可以在任何预置或自己的节点下添加子标签（例："自然 / 湖 / 西湖"），也可以新建根（例："人物"）。
- 层级不限；同一父节点下同一用户的标签不能重名。
- 自己的标签可以改名、移动（换父节点）、调整顺序、设置颜色、删除。删除会连同子孙一起删除，并解除这些标签与照片的关联。
- 预置标签只有站长和管理员能修改。
- 用户看到的标签 = 预置 + 自己的。访问他人主页时看到预置 + 该用户的标签。

# 自动建议

上传时根据数据建议标签（默认选中，可取消），记录为 `suggested` 来源：

| 依据 | 建议 |
|---|---|
| 地点类别 | 桥→桥、湖→湖、山→山、寺→寺、塔→塔、海岸/岛→海、街区→街头、建筑/美术馆→建筑 |
| 拍摄时刻与太阳高度 | 晨光 / 白昼 / 日落 / 蓝调 / 夜 |
| 日期与南北半球 | 春 / 夏 / 秋 / 冬 |
| 主色 | 暖 / 冷 / 绿 / 蓝 / 黑白 |

# 筛选

- 选中父标签 = 选中它的所有子孙（照片带"西湖"，筛"湖"和"自然"都能找到）。
- 多个标签之间是"并且"。
- 图库里每个根是一行；第二层作为分组标签显示，后面跟它的子标签；更深的层级在选中上层后展开。

# 验收

- 新建标签后无需刷新即可在上传页和图库使用。
- 不能把标签移动到自己的子孙下面（接口返回 400）。
