# 接口

* [接口约定](conventions.md) - 认证、错误格式、可见性与位置精度规则、缓存
* [认证与站点](auth.md) - 注册、登录、当前用户、站点信息、个人资料
* [照片](photos.md) - 列表、详情、上传、修改、删除
* [媒体](media.md) - 尺寸图与原图的读取规则
* [标签](tags.md) - 标签树的读取与增删改
* [地点](pois.md) - 地点列表、详情、匹配、搜索、新建
* [记录](entries.md) - 记录的列表、详情、创建、修改与删除，版本号防覆盖
* [附件](attachments.md) - 视频、录音和其他文件：分片上传、视频的画面、删除，`/media/a` 下按所在记录的权限读取
* [媒体库](library.md) - 自己的附件在哪条记录里、什么时候删去，各类文件有多少多大，记录用到的照片
* [项目](projects.md) - 项目的列表、详情、创建、修改与删除，以及里程碑
* [合集](themes.md) - 合集（接口里叫主题）与条目：照片、记录、文字、日期分段
* [分享链接](shares.md) - 记录、合集、项目的分享链接：新建、列出、删除、打开
* [搜索](search.md) - 在自己的档案里按字搜索，分组返回，带总数和片段
* [导出](export.md) - 按页读出自己的整个档案；导出文件的格式
* [导入](import.md) - 先问哪些已经在这里，再一批批送来标签、地点、隐私区域、项目、记录和合集；导入给的 id
* [回顾](review.md) - 自己档案里有记录或照片的年份，一年的每一天、类型、地点、标签、项目、合集和收藏
* [用户与管理](users-admin.md) - 个人主页数据、邀请码、站点设置、隐私区域
