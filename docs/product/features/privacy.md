# 公开范围

| 值 | 照片 | 主题 |
|---|---|---|
| `public` | 出现在图库、地图、索引、Living | 出现在主题列表 |
| `unlisted` | 只能通过链接访问 | 只能通过链接访问 |
| `private` | 只有本人 | 只有本人 |

新照片默认 `public`，新主题默认 `private`。

# 位置精度（对他人生效）

| 值 | 坐标 | 朝向 | 地点 | 到地点的距离 | 区县 |
|---|---|---|---|---|---|
| `exact` | 原值 | 显示 | 显示 | 显示 | 显示 |
| `fuzzy` | 四舍五入到约 500 米 | 隐藏 | 显示 | 隐藏 | 显示 |
| `hidden` | 隐藏 | 隐藏 | 隐藏 | 隐藏 | 隐藏 |

省份和城市始终显示。本人永远看到原值。

`fuzzy` 仍显示地点，但不显示「距地点多少米」：地点有精确坐标，再给出距离，取整后的位置就又缩回到几十米内。

# 隐私区域

在设置里添加（名称、中心、半径，默认 300 米）。落在区域内的照片位置强制设为 `hidden`：

- 添加区域时，本人坐标落在区域内的已有照片立即改为 `hidden`，设置页显示改了几张。设隐私区域就是为了让这一带不被别人看到，只管以后的上传不够。
- 之后上传的照片落在区域内也强制设为 `hidden`，匹配接口返回区域名，上传页显示"在隐私区域「家」内"。
- 删除区域不会恢复照片原来的位置精度，需要时到编辑页逐张改回。

# 自建地点

自己建的地点，在有公开且显示位置的照片用上它之前，只出现在自己的地点匹配和搜索里。规则见 [pois 的隐私](/data/pois.md#隐私)。

# 文件

- 原图存放在 R2 的 `o/` 前缀下，只有本人能下载。
- 公开展示的三种尺寸由浏览器重新编码，不含 EXIF。
- 私密照片的尺寸图也只对本人返回。
