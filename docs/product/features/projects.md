# 用户故事

- 开始学书法：建一个项目「从零开始学书法」，类型选学习，开始日期是今天。
- 每次练完字，在项目页点「记一笔」：新记录已经放进这个项目、类型是练习，拍下当天的字加进去，写两句心得。
- 打开「今天」，「进行中」里列着这个项目，第 37 天，今天已经记过了。
- 临完第一本字帖，加一个里程碑，写下这一阶段的总结；项目页上，这之前的练习和作品归到这一阶段，之后的归到「现在」。
- 半年后打开项目页，「最初与最近」把第一次的字和最近的字并排放着。
- 把项目设为公开，朋友能看到其中公开或仅链接的练习，看不到仅自己可见的那几条。

# 规则

- **入口**：档案下的「项目」页（与时间线并列）、「今天」的「进行中」、个人主页。主导航不变。
- **项目**：名称、类型（学习、练习、阅读、创作、其他）、开始日期、可选的结束日期（计划或实际）、Markdown 说明、状态（进行中、暂停、已完成）和公开范围。新项目默认仅自己可见、进行中。标为已完成时，没有结束日期就填上今天。
- **记录**：在编辑器的「项目」里选，可以选几个，也可以不选；只列出进行中和暂停的项目，以及这条记录已经在的。从项目页（或「今天」）点「记一笔」时预先选好这个项目，类型按项目定：学习、练习 → 练习，阅读 → 阅读，创作 → 创作，其他 → 随记。
- **项目页**：
  - 顶部：类型、状态、日期，「第 N 天」或「历时 N 天」，记录数、天数、照片数。
  - **最初与最近**：最早和最近一条带照片的已完成记录的第一张照片，并排；照片不足两张时不显示。
  - **阶段**：每个到达的里程碑（日期不晚于今天）结束一个阶段，列出这一阶段的日期、记录数、作品和总结；最后一个里程碑之后是「现在」，项目已完成时叫「完成」。日期在以后的里程碑列在后面，标「计划」。没有里程碑时只有作者看到这一节，用来添加。
  - **记录**：项目里的记录，最近的在前；作者还看到草稿（标「草稿」），已归档的不显示。
- **列表**：「项目」页按进行中、暂停、已完成分组，组内最近练过（最近一条记录或最近一次修改，取较晚的）的在前；卡片显示最近的作品、名称、天数和统计。
- **今天**：「进行中」列出已经开始的进行中项目，各带「记一笔」；今天有已完成记录的打勾。
- **统计**只算已完成的记录；草稿和已归档的不计。
- 删除项目只删项目和它的里程碑，记录留在档案里。

# 可见性

- 公开的项目出现在个人主页；仅链接的凭地址打开；仅自己的只有作者能看到。状态不影响可见性。
- 项目不改变其中记录和照片的公开范围：他人在项目页上只看到自己凭链接能打开的记录（已完成，公开或仅链接）和照片，统计和封面也只算这些。见 [隐私](/product/features/privacy.md#项目)。
- 记录页列出它所属的项目时，他人只看到公开的项目。
- 作者在项目页点「分享」建 [分享链接](/product/features/sharing.md)：拿到的人能看到这个项目、里程碑和其中已完成的记录与照片，包括仅自己可见的。
