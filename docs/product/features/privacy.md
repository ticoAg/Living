# 公开范围

| 值 | 照片 | 记录、项目 | 合集 |
|---|---|---|---|
| `public` | 出现在图库、地图、索引、Living | 出现在个人主页；记录还出现在地图的记录图层 | 出现在合集列表和个人主页 |
| `unlisted` | 只能通过链接访问 | 只能通过链接访问 | 只能通过链接访问 |
| `private` | 只有本人 | 只有本人 | 只有本人 |

新记录、新项目、新合集默认 `private`；新照片按账号的设置，见 [新照片](#新照片)。任何迁移都不改变已有内容的公开范围。

# 新照片

- 设置里的「新照片 · 默认公开范围」决定上传页给每张新照片预先选好的公开范围；上传时仍可逐张、或选中几张一起改。
- 新账号默认「仅自己」：照片上传后只有自己看得到，要进图库、地图要自己改成公开。上传页顶部一直写着当前的默认值，并链到设置。
- 这项设置出现之前就有的账号保持「公开」，与之前的上传行为一致，直到自己修改。
- 改设置只影响以后的上传；已经上传的照片在照片编辑页逐张改。

# 记录

- 公开范围只对已完成的记录生效：草稿和已归档的记录对他人一律不可见，按不存在处理。
- 记录不改变其中照片的公开范围：他人看一条公开记录时，只看到自己有权打开的照片，其余直接略去。编辑器在记录里有仅自己可见的照片时提醒。
- 个人主页的记录数、标签的记录数、照片页的「所属记录」都只算他人能看到的。
- 仅链接的记录凭地址打开；要收回，改为仅自己或改回草稿。只想给几个人看，用 [分享链接](#分享链接)。
- 想确认别人看到什么：在自己的主页、记录、合集或项目页上点「访客视角」，页面按没登录的样子重新读取，见 [访客视角](/product/features/showcase.md#访客视角)。
- 记录的地点：能看到记录的人都能看到。地点在自己的隐私区域内时编辑器提醒，不会自动隐藏。
- 地图的记录图层只有公开且已完成的记录，放在它的地点，没有地点时放在它某张照片的位置；照片只算看的人能打开的，位置照旧按 [位置精度](#位置精度对他人生效)，位置隐藏的照片不会把记录带上地图。
- 编辑器在这台设备上暂存还没保存的改动，按账号分开存，退出登录时清除。

# 附件

- 附件（视频、录音和其他文件）没有自己的公开范围，跟着所在的记录：能打开记录的人，包括凭分享链接打开的人，就能播放、下载它的附件。只想留给自己的录音，放在仅自己可见的记录里。
- 还没放进记录的、从记录里去掉的附件只有自己能读到，七天后删去。
- 手机拍的视频和语音备忘录里写着的拍摄地点，上传前在浏览器里抹掉；其他文件按原样上传，见 [附件](/product/features/attachments.md#位置)。
- 附件的文件不进缓存：记录改为仅自己可见后，别人马上就读不到。

# 项目

- 新项目默认仅自己可见。
- 项目不改变其中记录和照片的公开范围：他人在公开（或仅链接）的项目里只看到自己凭链接能打开的记录和照片，项目的记录数、照片数和封面也只算这些。仅自己可见的记录、草稿和已归档的记录不会因为项目公开而被看到或被计数。
- 记录页、个人主页只列出他人能在列表里看到的项目（公开的）；仅链接的项目凭地址打开。

# 合集

- 新合集默认仅自己可见。
- 合集不改变其中照片和记录的公开范围：读者只看到自己凭链接能打开的照片和记录，合集的照片数、记录数、封面、路线和地点也只算这些。仅自己可见的照片和记录、草稿和已归档的记录不会因为合集公开而被看到或被计数。
- 编辑器在公开或仅链接的合集里提醒「有几张照片、几条记录读者看不到」，每一行也标出原因（仅自己可见、草稿、已归档）。
- 记录页、照片页只列出他人能在列表里看到的合集（公开的）；仅链接的合集凭地址打开。

# 分享链接

作者为自己的一条记录、一个合集或一个项目建的私密地址，见 [分享链接](/product/features/sharing.md)。

- 拿到链接的人不用登录就能看到这一项和其中的内容，包括仅自己可见的；看不到草稿、已归档的记录和原图，位置精度照旧。
- 只放开这一项：列表、主页、图库、地图、搜索和计数照旧只算公开的内容。
- 删掉链接或链接过期，立刻打不开。删除内容时，它的链接一并删除。
- 链接就是钥匙，转给谁谁就能打开；仅链接的平常地址没有这种「收回」。

# 搜索与导出

- [搜索](/product/features/search.md) 只搜自己的内容：结果和每组的数目都只来自自己的记录、照片、项目、合集，以及自己用到的地点和标签。别人的内容不管公开与否都不在其中，搜索不会让人看到自己的页面上本来看不到的东西。
- [导出](/product/features/export.md) 只有本人能做，读出自己的全部内容，包括仅自己可见的、草稿和已归档的记录、附件、原图和其中的 EXIF；不读出密码、会话和分享链接的地址。导出的文件由自己保管。
- 原图仍只对本人开放：导出读原图用的是同一个地址（`/media/o/…`），别人拿到也读不到。
- [导入](/product/features/import.md) 只写进自己的账号。照片的位置以 living.json 为准，不从原文件的 EXIF 重新读：在原站点去掉的位置不会回来；落在自己隐私区域里的照片照样隐藏位置。公开范围照导出里的，也可以全部设为仅自己可见。

# 位置精度（对他人生效）

| 值 | 坐标 | 朝向 | 地点 | 到地点的距离 | 区县 |
|---|---|---|---|---|---|
| `exact` | 原值 | 显示 | 显示 | 显示 | 显示 |
| `fuzzy` | 四舍五入到约 500 米 | 隐藏 | 显示 | 隐藏 | 显示 |
| `hidden` | 隐藏 | 隐藏 | 隐藏 | 隐藏 | 隐藏 |

省份和城市始终显示。本人永远看到原值。

`fuzzy` 仍显示地点，但不显示「距地点多少米」：地点有精确坐标，再给出距离，取整后的位置就又缩回到几十米内。

# 隐私区域

在设置里添加（名称、中心、半径，默认 300 米）。落在区域内的照片位置强制设为 `hidden`：

- 添加区域时，本人坐标落在区域内的已有照片立即改为 `hidden`，设置页显示改了几张。设隐私区域就是为了让这一带不被别人看到，只管以后的上传不够。
- 之后上传的照片落在区域内也强制设为 `hidden`，匹配接口返回区域名，上传页显示"在隐私区域「家」内"。
- 删除区域不会恢复照片原来的位置精度，需要时到编辑页逐张改回。

# 自建地点

自己建的地点，在有公开且显示位置的照片用上它之前，只出现在自己的地点匹配和搜索里。规则见 [pois 的隐私](/data/pois.md#隐私)。

# 文件

- 原图存放在 R2 的 `o/` 前缀下，只有本人能下载。
- 公开展示的三种尺寸由浏览器重新编码，不含 EXIF。
- 私密照片的尺寸图也只对本人返回。
- 附件存放在 R2 的 `a/` 前缀下，按所在记录的权限读取；上传的网页、SVG 这类文件只能下载，不会在站点上运行。
