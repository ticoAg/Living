# 结构

1. 封面大图（圆角，在页面边距之内）、标题（宋体）、副标题、作者、日期范围、照片数、记录数（有记录时）与地点数。
2. 导语。
3. 路线地图（旅程）：按顺序连接有位置的照片，记录里的照片也算；地点作为标记，点击跳到这个地点第一次出现的照片或记录。
4. 正文：按条目顺序排版。
   - 日期分段显示为"第 N 天 · 10月3日 周六"。
   - 照片按原比例大图显示，下方是地点、时间和笔记。
   - 记录是一张卡片：合集写在它前面的话、类型和时间（在当天的分段下只写时刻）、标题、开头一段、最多 6 张照片（更多的显示"+N"，链到记录），正文没完时有「读全文」。
   - 文字段落用正文样式。
5. 结尾：途经地点列表（链接到地点页）、作者的其他合集。

# 规则

- 只显示读者有权看到的照片和记录；隐藏位置的照片不出现在路线上。
- 本人在阅读页右上角看到"编辑"。
- 可从这里进入 Living 模式，按合集的顺序播放其中的照片和记录里的照片（`/living?src=theme&theme=<id>`）。
- 分享链接为 `/t/<id>`；仅链接可见的合集不出现在列表中。
