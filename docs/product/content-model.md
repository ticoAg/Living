# 四个概念

| 概念 | 是什么 | 例子 | 现状 |
|---|---|---|---|
| 记录 Entry | 某个时间发生的事、一个想法、一次练习或一项创作；可以只有文字 | 今天练了一页字；读完《长安的荔枝》第三章 | 第一阶段，见 [记录](/product/features/entries.md) |
| 媒体 Media | 记录可以关联的文件，目前是照片 | 一张断桥的照片 | 沿用 [照片](/data/photos.md)，记录经 [entry_media](/data/entry-media.md) 引用 |
| 项目 Project | 持续的目标、学习或创作过程，聚合记录和里程碑 | 从零开始学书法；一年读书计划 | 第二阶段，见 [项目](/product/features/projects.md) |
| 合集 Collection | 从不同时间、不同项目里挑出照片和记录，排好顺序，配上标题和导语 | 西湖四季；我的书法作品 | 第三阶段，见 [合集](/product/features/themes.md)；由原来的主题原地演进 |

# 边界

- **记录优先于整理**：写下一条记录不需要先选类型、地点、项目或合集，这些都可以以后补。
- **媒体是附件，不是前提**：一条记录可以只有文字。照片笔记仍是那张照片的说明，不是记录。
- **项目关注过程，合集关注展示**：同一条记录可以属于一个项目，又被选进几个合集；不强制记录属于项目。
- **媒体有自己的属性**：照片的公开范围、标签、地点属于照片本身，记录引用它时不改变它们。删除记录不删除照片；删除照片时它从引用它的记录里消失。
- **一棵标签树，分开挂**：记录和照片用同一套 [多层级标签](/product/features/hierarchical-tags.md)，但给记录打「书法」不等于给它的照片打。

# 关系

| 关系 | 基数 | 落在 | 阶段 |
|---|---|---|---|
| 作者 — 记录 | 一对多 | `entries.owner_id` | 一 |
| 记录 — 照片 | 多对多，有顺序和记录内说明 | [entry_media](/data/entry-media.md) | 一 |
| 记录 — 标签 | 多对多 | [entry_tags](/data/entry-tags.md) | 一 |
| 记录 — 项目 | 多对多，只能放进作者自己的项目 | [entry_projects](/data/entry-projects.md) | 二 |
| 项目 — 里程碑 | 一对多 | [milestones](/data/milestones.md) | 二 |
| 合集 — 照片、记录、文字、日期分段 | 有序条目，只能放作者自己的照片和记录 | [theme_items](/data/theme-items.md) | 三 |
| 记录 — 地点 | 可选 | 待定，复用 [地点](/data/pois.md) | 三 |

# 记录的类型

`随记`（默认）、`文章`、`阅读`、`练习`、`创作`、`旅行`。类型只决定显示的名字和筛选，不带各自的表或必填字段；类型会增加。各类型特有的结构化数据（书名、练习时长）暂不做，需要时再评估扩展字段，不把所有类型的数据塞进一个通用列。

# 时间

| 字段 | 含义 | 例子 |
|---|---|---|
| 发生时间 `occurredAt` | 事情实际发生的时间，本地时间，可以只有日期 | 今天补录去年的旅行：`2025-05-02` |
| 写下时间 `createdAt` | 记录创建的时间 | 今天 |
| 修改时间 `updatedAt` | 最后一次修改 | |

时间线、今天、往年今天都按发生时间；草稿按修改时间。只有日期的记录排在当天有时刻的记录之后。

# 状态

| 状态 | 意义 | 他人能否看到 |
|---|---|---|
| 草稿 `draft` | 还在写 | 不能，无论公开范围 |
| 已完成 `published` | 写完了 | 按公开范围 |
| 已归档 `archived` | 收起来：不在今天、主页和默认的时间线里出现，但保留 | 不能 |

状态与公开范围相互独立。把一条公开记录改回草稿或归档，它就暂时对他人不可见，不必改公开范围；恢复后按原来的公开范围重新可见。

# 可见性

- **新内容默认仅自己可见**：记录、项目、合集如此；新账号上传的照片也是，见 [隐私](/product/features/privacy.md#新照片)。公开必须由作者主动选择。
- 三档与照片相同：公开（进入主页和列表）、仅链接（凭链接打开）、仅自己。
- **容器不传染**：公开的记录不会公开其中仅自己可见的照片，公开的项目、合集不会公开其中的私密记录和照片。容器里显示和计数的，是读者凭链接本来就能打开的内容。
- **处处同一套规则**：列表、详情、计数（个人主页、标签的记录数、项目和合集的统计）、照片页的「所属记录」「所属合集」、记录页的所属项目和合集都按它过滤，见 [entries 的可见性](/data/entries.md#可见性)。
- 已有账号的照片上传仍默认公开，直到自己在设置里改，理由见 [数据演进](/data/evolution.md#照片的默认可见性)。

# 兼容

图库、地图、索引、Living 和游记照旧，旧页面和接口不变；照片笔记仍在照片上。原来的主题原地成为合集，地址、内容和顺序不变；旅程为什么没有变成项目，见 [数据演进](/data/evolution.md#合集)。
