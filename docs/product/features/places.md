# 内容

- 地点名用宋体大字号排版，按名字的长度撑满左栏；类别符号、城市与区县、坐标。
- 统计：照片数、时间跨度、匹配半径。
- 地图：地点中心、匹配半径虚线圈、每张照片的拍摄点和朝向扇形。
- 筛选：时段（晨 昼 暮 夜）、季节（春夏秋冬）；不在结果里的拍摄点变淡。
- 照片瀑布流（排法与 [图库](/product/features/gallery.md) 相同，最新的在第一行），每张下方是标题（一行）和日期。
- 附近地点（5 公里内、有可见照片），按距离排序。
- Living：只播放这个地点的照片。
- 编辑：右上角的按钮，只对能修改这个地点的人显示，打开 [编辑页](#编辑)。

# 规则

- 多位用户在同一地点拍的公开照片都会出现，标注拍摄者。
- 地点的创建者、站长和管理员可以修改地点名、类别、别名和匹配半径，见 [编辑](#编辑)。

# 编辑

`/studio/place/:id`，和 [照片编辑](/product/features/upload.md#编辑) 一样放在 studio 分区，改完点"保存修改"。

- 名称：1 到 80 个字符。
- 类别：17 个类别里选一个，每个都带地图符号。
- 别名：加几个都行（最多 20 个，每个最多 80 个字符）。[按名称搜索地点](/api/pois.md) 时别名和名称一起被匹配，所以"断桥残雪"能找到"断桥"。输入框里还没点"添加"的别名，保存时一并保存。
- 匹配半径：10 到 5000 米。拖动滑块，它按整数档走（10、15、20 …… 5000，每个类别的默认半径都在其中），也可以直接输入。旁边的小地图以地点中心画出这个半径的虚线圈，随改随变；中心点本身不能改。

规则：

- "编辑"只对创建者和站长、管理员显示。别人打开这个地址只看到一句说明（没登录的先去登录），接口也会拒绝（403）。
- 只发送改过的字段。保存后地点页、地图、索引、照片页和主题里的地点立刻显示新值。
- 半径只影响以后的匹配，已经匹配好的照片不会重新匹配。
- 服务端拒绝时，原因显示在保存按钮旁，填好的内容不会丢。有未保存的修改时离开页面会先确认。
- 接口细节见 [地点接口](/api/pois.md)；数据见 [pois](/data/pois.md)。
