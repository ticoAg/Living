# 预置标签树

由迁移 `migrations/0002_preset_tags.sql` 写入，`owner_id` 为空，所有人可见：

- 题材：自然（湖 山 海 河 树 花）、城市（街头 建筑 夜景）、人文（桥 塔 寺 展馆）、生活（室内 美食 茶 人 宠物）
- 光与天气：光线（晨光 白昼 日落 蓝调 夜）、天气（雾 雨 雪）
- 季节：春 夏 秋 冬
- 色调：暖 冷 绿 蓝 黑白（带颜色，显示为色块）

# 自定义

- 用户可以在任何预置或自己的节点下添加子标签（例："自然 / 湖 / 西湖"），也可以新建根（例："人物"）。
- 层级不限；同一父节点下同一用户的标签不能重名。
- 自己的标签可以改名、移动（换父节点）、调整顺序、设置颜色、删除。删除会连同子孙一起删除，并解除这些标签与照片的关联。
- 预置标签只有站长和管理员能修改。
- 用户看到的标签 = 预置 + 自己的。访问他人主页时看到预置 + 该用户的标签。

# 打标签

上传页和照片编辑页用同一块标签板（`src/studio/TagPicker.tsx`，逻辑在 `src/studio/tag-board.ts`）：

- 所有标签直接摆出来，每个根一行：题材、光与天气、季节、色调，再是用户自己的根。第二层（自然、城市、光线、天气……）是一行里的小标签，后面跟它的子标签；更深的标签紧跟在父标签后面。点一下选中，再点取消，不用展开树。
- 季节、光线、色调各只能有一个：选"秋"会去掉"春"，选"夜"会去掉"晨光"。天气、题材和用户自己的标签可以任意组合。
- 预置的根（题材、季节……）只是行首的名字；用户自己的根也能直接选。
- 顶部的搜索框按名称筛出标签；没有同名的标签时给出"新建「…」"，选择放在哪个标签下面（默认最上层），新建后自动选中。"管理"打开标签管理页。
- 不再根据地点、时间或颜色自动建议标签：标签全部由人选。
- 上传页的"标签和设置套用到其余 N 张"把当前照片的标签加到其余未发布的照片上；季节、光线、色调冲突时以当前照片为准。

# 筛选

- 选中父标签 = 选中它的所有子孙（照片带"西湖"，筛"湖"和"自然"都能找到）。
- 多个标签之间是"并且"。
- 图库里每个根是一行；第二层作为分组标签显示，后面跟它的子标签；更深的层级在选中上层后展开。

# 验收

- 新建标签后无需刷新即可在上传页和图库使用。
- 不能把标签移动到自己的子孙下面（接口返回 400）。
