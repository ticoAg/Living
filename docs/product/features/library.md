# 用户故事

- 想知道自己在这里存了多少东西：照片多少张、视频多少个，一共多大。
- 上周传了一段视频，记录没写完就关了：在媒体库的「视频」里找到它，写着「不在记录里 · 3 天后删去」，选上它写一条记录，它就留下来了。
- 一批照片传上来以后从没写过记录：选「不在记录里」，挑几张，「写一条记录」，编辑器里已经放好这几张，日期是其中最早那张的拍摄日。
- 一个早就不要的录音占着地方，又不在任何记录里：删掉。

# 页面

登录后的「图库」里，「照片 / 地图 / 索引 / 媒体库」的最后一个，地址 `/library`。只有自己的；没登录时请先登录。

- 标题旁是这些文件一共多大。
- 四张卡片是四类，各写数量和大小，同时是切换：
  - **照片**：自己的全部照片，大小算原文件（尺寸图不算）。
  - **视频**、**音频**、**文件**：自己的附件，大小只算传完了的。
- 卡片下面是筛选，各带数量：
  - 照片：全部、不在记录里、公开、仅链接、仅自己。
  - 附件：全部、不在记录里（没传完的也算）。
- 地址栏记着类型和筛选：`/library?kind=video&show=loose`；换类型时筛选回到全部。

## 照片

- 方格，新拍的在前，没有拍摄时间的在最后；格子左下是拍摄日期。点开是照片页，上一张、下一张走的是这里的列表。
- 先显示 240 张，「显示更多」再接 240 张。照片超过 5000 张时只有最新的 5000 张，写一行「只显示最近的 5000 张」。

## 附件

每个一行：视频有封面，其余是图标；名字（点开在新页面里打开或播放）、时长、大小、日期；下面是它在哪里：

- 在记录里：记录的名字（点开是记录，草稿打开编辑器）、发生日期、状态（不是已完成时）和公开范围。
- 不在记录里：「不在记录里 · 6 天后删去」；一天之内写几小时后；到时间而清理还没运行时写「即将删去」。
- 没传完：「没传完 · 20 小时后删去」。没传完的只能删掉，不能在这里接着传。

右边是下载，和不在记录里的才有的删除：点删除再点「确认删除」，文件和它一起删去。在记录里的先在记录里去掉。

# 写一条记录

- 「选择」后点照片和不在记录里的附件选上，切换类型时选的还在；底部一栏写已选几样，「清除选择」「写一条记录」。再点「取消」退出选择，什么也不留。
- 在记录里的、没传完的附件选不了；照片在不在记录里都能选，一张照片可以在几条记录里。
- 「写一条记录」打开新记录的编辑器：照片按拍摄时间排好，附件跟在后面，都没有说明；日期是选中的照片里最早的拍摄日，都没有拍摄时间时是今天。新记录照常仅自己可见，编辑器不提「本机有未保存的副本」。
- 一条记录最多 200 张照片、20 个附件，选多了按不了，并写明原因。

# 规则

- 列表来自 [媒体库接口](/api/library.md) 和照片列表的 `mine=1`。写完记录、上传或删除照片、删除附件以后，媒体库再打开时重新读取。
- 不在记录里的附件由每小时的清理删除：没传完的一天后，不在记录里的七天后（见 [附件](/product/features/attachments.md)）。媒体库只是让人看见它们，规则不变。
- 附件最多列出最新的 5000 个，更多时写一行「只显示最近的 5000 个」。
