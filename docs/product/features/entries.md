# 用户故事

- 练完字，在「今天」写一句「今天练了一页《九成宫》，横画还是太重」，按记下。不用选类型、地点或合集。
- 晚上打开这条记录，补上标题，加两张练习的照片，各写一句说明，打上「书法」。
- 补录去年的一次旅行：把日期改成去年五月，选几张那几天的照片，写成一篇长文，设为公开。
- 在手机上写了一半，地铁里没信号：文字先留在手机上，有网时自动保存。

# 写

- **随手记**：[今天](/product/features/today.md) 顶部的输入框。记下即为一条已完成的随记，发生时间是此刻，仅自己可见；Ctrl/Cmd+Enter 也能记下。没记下的文字留在这台设备上。
- **写长文**：把输入框里的文字带进编辑器继续写；也可以从 `/entries/new` 直接开始。从 [日历](/product/features/calendar.md) 补记某一天时是 `/entries/new?date=YYYY-MM-DD`：日期就是那天，以前的日子只有日期、不带时刻。
- **从媒体库**：在 [媒体库](/product/features/library.md#写一条记录) 里选几张照片和不在记录里的附件，「写一条记录」打开新记录，它们已经放好，日期是照片里最早的拍摄日。
- **编辑器**：类型、日期、时间（可勾「全天」只留日期）、标题、正文、照片、附件、地点、项目、标签、公开范围。正文用 Markdown，可切换「预览」。
- **照片**：只能从自己的照片里选，默认显示与记录同一天拍的；每张可以写一句这条记录里的说明，可调整顺序、移除。移除不会删除照片，说明不改变照片自己的 [笔记](/product/features/photo-notes.md)。
- **附件**：视频、录音和其他文件，在编辑器里添加或直接录音，边传边写，每个可以写一句说明，见 [附件](/product/features/attachments.md)。随手记也能录音。
- **地点**：可选，一条记录一个。先列出这条记录的照片所在的地点，点一下即选上；也可以按名称搜索（有带位置的照片时搜它附近），搜到地图数据源里的地点时顺手建成站内地点。与照片的地点相互独立。能看到记录的人都能看到它的地点；地点在自己的 [隐私区域](/product/features/privacy.md#隐私区域) 内时编辑器会提醒。
- **标签**：与照片共用 [多层级标签](/product/features/hierarchical-tags.md)，但分开打。

# 保存

- 停止输入一会儿就自动保存；Ctrl/Cmd+S 立即保存；离开页面或切到后台时也会保存。底部显示保存状态。
- 新记录写下第一个字时以草稿保存，地址变为 `/e/:id/edit`；按「完成」变为已完成并打开阅读页。
- 保存前的改动同时留在这台设备上。下次打开时如果这台设备上有服务器没有的版本，会询问恢复还是丢弃。退出登录时清除。
- 同一条记录在别的窗口或设备上改过时，停止自动保存并提示：载入那边的版本，或用这里的覆盖。记录在别处被删除时，可以另存为新记录。
- 空的记录（没有标题、正文、照片和附件）不保存。

# 状态与公开范围

- **状态**：草稿、已完成、已归档。草稿只有自己能看到；已归档的不出现在今天、个人主页和档案的默认视图里，在档案里打开「已归档」可以找到，随时可以取消归档。
- **公开范围**：仅自己（默认）、仅链接、公开，只对已完成的记录生效。编辑器在选项下说明后果。
- 已完成的「创作」和「文章」排在个人主页最前面，各有一页，见 [作品与文章](/product/features/showcase.md)。
- 记录公开不等于其中的照片公开：照片各有自己的公开范围，他人看不到的照片在记录里直接略去。记录里有仅自己可见的照片而记录不是仅自己时，编辑器会提醒。附件没有自己的公开范围，跟着记录。
- 删除记录需要确认，照片不受影响，附件随记录一起删除；它从收录它的合集里消失。

# 阅读

- `/e/:id`：所属的项目、日期、地点（链到 [地点页](/product/features/places.md)）、类型、标题（没有标题时以日期作标题）、正文、照片和说明、附件、收录它的 [合集](/product/features/themes.md)、标签。作者看到「分享」「访客视角」和「编辑」；草稿显示「继续写」。
- 看得到照片时，最下面有 Living：按这条记录里的顺序全屏播放这些照片，字幕写着记录的名字（见 [Living 模式](/product/features/living-mode.md#记录)）。
- 列表里的记录卡片也显示地点和附件。
- 「分享」生成 [分享链接](/product/features/sharing.md)：拿到的人能看这条记录、它的全部照片和附件；记录要已完成，链接才打得开。
- 照片可点开到照片页；照片页列出它所属的记录。
- 合集可以收录记录：合集里显示它的标题、开头一段和照片，链回这里。只列他人能在列表里看到的合集（公开的）；作者看到自己的全部。
- 他人只能打开已完成且公开或仅链接的记录（或凭作者给的分享链接），其余一律显示「记录不存在，或你没有权限查看」。

# Markdown

支持标题、段落（单个换行保留为换行）、引用、列表与任务列表、代码块、分隔线、粗体、斜体、删除线、行内代码和链接。HTML 按原文显示；图片语法显示为指向图片的链接，记录不加载外部图片；链接只允许 http(s)、mailto 和站内地址。
