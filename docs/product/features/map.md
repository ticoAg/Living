# 内容

- MapLibre 底图（OpenFreeMap 矢量瓦片，重新配色为纸面陆地、淡蓝水面、安静的道路）。
- 有可见照片的地点显示为圆形计数标记加地点名；选中的标记反色。
- 顶部筛选：季节（春夏秋冬）、光与天气（晨光 日落 蓝调 夜 雾 雨 雪）。筛选后标记计数随之变化，为 0 的变淡。
- 城市切换：按照片所在城市快速定位。
- 侧栏：地点名（宋体加宽字距）、类别、坐标、照片数、缩略图网格、"打开地点"和 Living（只播放这里的照片）。

# 规则

- 只统计访客可见、位置未隐藏的照片。
- 初始视野包含全部标记；地址栏记录选中地点（`?poi=<id>`）。
