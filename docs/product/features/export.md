# 用户故事

- 年底想留一份完整的副本：在设置的「导出」里点「下载 zip」，得到一个文件夹，用 Obsidian 打开就能按年份翻记录，图片也在。
- 每个月备份一次：第一次「导出到文件夹」选移动硬盘上的一个文件夹；以后每次选同一个文件夹，只下载这个月新加的照片，删掉的照片和记录也从文件夹里清掉。
- 只想要文字：关掉「包含照片原文件」，几秒钟导出全部记录和 living.json。

# 规则

- **入口**：[设置](/product/features/accounts.md) 的「导出」，写着记录、照片、项目、合集的数目和原文件一共多大。
- **包含照片原文件**：默认打开。关掉后不下载任何照片；导出到文件夹时，之前导出的照片原文件留着，Markdown 照样链接它们。
- **下载 zip**：每个 zip 约 1 GB，原文件多就分成几个（`living-ada-2026-11-17-1.zip`、`-2.zip`……，只有一个时不带编号），做好一个就下载一个，页面上也列出来可以再点。每个 zip 解压出来都是 `living-ada/` 文件夹，解压到同一个位置就合成一个；living.json 和 Markdown 在最后一个里。浏览器问是否允许下载多个文件时选允许。
- **导出到文件夹**：Chrome、Edge 的电脑版有这个按钮。选一个文件夹，导出写进其中的 `living-ada/`（直接选 `living-ada/` 本身也行）。
  - 再次导出到同一个文件夹：路径和大小都对得上的照片不再下载；上次导出写过、这次没有的文件删掉（照片删了、记录改了标题），只删 living.json 里列着的、导出自己写的文件，文件夹里自己放的其他东西不动。
  - 文件夹里是另一个账号的导出时不写，提示换一个文件夹。
  - 中途断了也不白费：已经写进文件夹的照片，下次不用再下载。
- **进度**：先读档案，再下载照片（按字节算），最后写记录、项目、合集和 living.json。可以随时取消；离开这一页也会停下，关标签页前浏览器会先问。
- **网络**：一次请求失败时等 1、4、15 秒再试，仍然失败才停下，说明原因。登录中途失效时停下，提示重新登录后再导出。
- **缺原文件**：原文件读不到的照片用 2560 像素的大图代替，大图也没有的只留信息；结束时写明有几张，README 和 living.json 里也有。

# 导出的文件

```
living-ada/
  README.md               这次导出里有什么
  entries/2026/2026-11-16 西湖边的一个下午.md
  projects/学吉他.md
  collections/杭州.md
  media/2026/2026-11-16_ph_01J….jpg
  media/undated/ph_01J….heic
  living.json             全部信息
```

- **记录**：每条一个 Markdown，按发生的年份分文件夹，文件名是日期和标题（没有标题时是正文开头）。开头的 frontmatter 是 id、类型、时间、状态、公开范围、地点、标签、项目和所属合集，正文后面是照片和说明。
- **项目**：说明、按日期排的里程碑，以及项目里的记录（链接到记录的文件）。
- **合集**：按原来的顺序排着日期分段、文字、照片和记录。
- **照片**：上传时的原文件，带着原来的 EXIF（拍摄参数和位置）。按拍摄的年份分文件夹，没有拍摄时间的在 `undated/`。
- Markdown 里的图片和链接都是相对路径，用 Obsidian、Typora 等编辑器打开这个文件夹就能看到照片。
- **living.json**：全部信息，字段见 [导出接口](/api/export.md#导出的文件)。

包括自己的全部内容，不管公开范围：草稿和已归档的记录、仅自己可见的照片、项目、里程碑、合集、自己建的和预置的标签、用到的和自己建的地点、隐私区域、分享链接的列表。不包括：密码和登录、分享链接的地址（导出里只有链接打开的是什么、何时过期，拿到导出的人打不开链接）、别人的内容、站点管理的数据。

# 隐私

- 只有本人能导出自己的档案，导出的文件含有原图的 EXIF 和全部位置，请像对待相册备份一样保管。
- 档案存放在站长的 Cloudflare 账号里（D1 存记录和元数据，R2 存照片），这是托管存储，不等于存在自己的电脑上。定期导出，手里才有一份完全由自己保管的副本。
- 导出可以 [导入](/product/features/import.md) 回 Living：换站点、找回删掉的内容都用它。整站的备份与恢复由站长按 [备份与恢复](/runbooks/backup.md) 做。

# 额度

导出在浏览器里完成，Worker 只按页读出档案、逐张返回原文件，所以档案再大也不会让 Worker 超时。但每张照片的原文件是一次请求：免费版每天 10 万次请求，2 万张照片的档案约占一天额度的五分之一，见 [费用](/architecture/cloudflare.md#费用)。导出到同一个文件夹时只下载新的照片，最省额度。
