# 用户故事

- 画了一年水彩，想给朋友看看：每幅画记一条类型为「创作」的记录，带上作品照片，写完后公开。它们排在主页最前面的「作品」里；作品多了，点「全部」看整页。
- 写过几篇长一点的文字，想集中放在一处：类型选「文章」，写完后公开，出现在主页的「文章」里，`/@handle/articles` 按年份列出全部。
- 有几篇还不想给人看：保持仅自己可见。自己的主页上它们标着「仅自己可见」，别人看不到；点「访客视角」确认一下。

# 作品

- 作品是类型为「创作」、已完成的 [记录](/product/features/entries.md)，草稿和已归档的不展示。
- 主页的「作品」：最新的 8 件，手机上两列，更宽的屏幕四列。每件一个格子：记录里第一张看得到的照片（4:5，按照片的焦点裁切），下面是标题和日期；没有照片，或照片看不到，就显示正文的开头。多于 8 件时标题旁有「全部 N」。
- 作品页 `/@handle/works`：全部作品，从新到旧，一次 48 件，「更多」接着往下。
- 点开就是那条记录的页面。

# 文章

- 文章是类型为「文章」、已完成的记录。
- 主页的「文章」：最新的 5 篇，每篇一行：标题、正文开头两行、日期和字数。没有标题的，用正文开头作标题。多于 5 篇时有「全部 N」。
- 文章页 `/@handle/articles`：全部文章，按发生的年份分组，从新到旧，一次 100 篇。
- 字数按正文写下的样子数：Markdown 原文，一个汉字、字母、标点或换行算一个；一万以上写作「1.2万字」。

# 主页的顺序

作品、文章、合集、项目、其余的记录、照片。作品和文章不在「记录」里重复出现。

# 公开

- 作品和文章就是记录，公开范围按记录的规则，见 [隐私](/product/features/privacy.md#记录)：别人只看到已完成、公开的；仅链接的凭地址打开，不出现在主页和这两页；仅自己的只有作者看得到。
- 作者在自己的主页和这两页上看到自己全部已完成的作品和文章，不公开的标着「仅链接可见」「仅自己可见」。
- 作品格子里的照片按照片自己的公开范围：别人看不到的照片不会因为作品公开而露出来，格子改为显示正文开头。

# 访客视角

在自己的主页、记录页、合集页和项目页上点「访客视角」，看这一页在没登录的人眼里的样子。

- 地址后面多了 `?as=visitor`，页面上方一条横栏写着「访客看到的样子」，点「退出」回到自己的视角。
- 这时页面里的请求都不带登录信息，看到的就是访客看到的：仅自己可见的内容不在，计数只算公开的，编辑、分享等按钮不出现；访客打不开的一页显示「不存在，或你没有权限查看」。
- 在里面点到访客也能打开的页面（主页、作品、文章、记录、合集、项目、照片、地点、图库、地图、索引），仍是访客视角；去别处（今天、档案、设置、编辑……）就回到自己的视角。页眉一直显示自己。
- 访客视角只改变这一页怎么读取，不改动任何内容，也不用退出登录。
