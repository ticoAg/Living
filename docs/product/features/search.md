# 用户故事

- 记得写过一条去西湖的记录，忘了是哪天：在任何页面按 `/`，输入「西湖」，记录、照片、合集和地点分组列出，片段里标出这两个字。
- 想找去年读完的一本书：搜书名，标题里有这几个字的记录排在最前面。
- 找练字时写过「中锋」的那几次：搜「书法 中锋」，两个词都出现的记录和项目才算，可以一个在标题里、一个在正文里。

# 规则

- **入口**：登录后页眉的放大镜，或在任何页面按 `/`（正在输入框里打字时不算）。地址是 `/search?q=西湖`，可以收藏。
- **找什么**：只找自己的内容，不管公开范围，草稿和已归档的记录也在内。

  | 分组 | 在哪些字里找 |
  |---|---|
  | 记录 | 标题、正文、照片说明 |
  | 照片 | 标题、笔记 |
  | 项目 | 名称、说明、里程碑的标题和内容 |
  | 合集 | 标题、副标题、前言，以及条目里的字：文字段落、日期分段的标题、照片和记录下的说明 |
  | 地点 | 名称和别名；只列出自己的照片或记录在那里的，以及自己建的 |
  | 标签 | 名称；只列出自己用过的预置标签和自己建的标签 |

- **怎么匹配**：按原样找字，出现在哪里都算：「西湖」能找到「西湖边」，也能找到「去西湖」。英文字母不分大小写。
- **几个词**：用空格分开，每个词都要出现，可以在不同的地方。带空格的词用引号括起来：`"new york"`、“西湖 边”、「西湖 边」。最多 5 个词、100 个字。
- **排序**：标题里有这些字的排前面，其余按时间从近到远（记录按发生时间，照片按拍摄时间，项目和合集按最近修改）；地点和标签按自己用过的次数。
- **结果**：每组先列前面的一部分（记录 50 条、照片 60 张、其余各 20 个），写着一共有多少；点「全部」看这一组的前 500 个。记录、项目和合集带一段含有这些字的原文，找到的字高亮。
- 停止输入 0.35 秒后自动搜索；用中文输入法打字的过程中不搜。

# 隐私

- 只搜自己的内容：别人公开的记录和照片不在结果里，搜索不会让人看到自己的页面上本来看不到的东西。
- 结果不进浏览器和中间服务器的缓存（`no-store`），服务器也不保存搜过什么。
- 搜索的字在地址里（`?q=`）：浏览器的历史记录会留下；站点开着 [Workers 日志](/architecture/cloudflare.md#资源) 时，站长在 Cloudflare 控制台的请求记录里也看得到。
