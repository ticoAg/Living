# 结构

1. 封面大图、标题（宋体加宽字距）、副标题、作者、日期范围、照片数与地点数。
2. 导语。
3. 路线地图（旅程）：按顺序连接有位置的照片，地点作为标记，点击跳到对应段落。
4. 正文：按条目顺序排版。日期分段显示为"第 N 天 · 10月3日 周六"；照片按原比例大图显示，下方是地点、时间和笔记；文字段落用正文样式。
5. 结尾：途经地点列表（链接到地点页）、作者其他主题。

# 规则

- 只显示访客有权看到的照片；隐藏位置的照片不出现在路线上。
- 本人在阅读页右上角看到"编辑"。
- 可从游记进入 Living 模式，只播放本主题的照片（`/living?src=theme&theme=<id>`）。
- 分享链接为 `/t/<id>`；仅链接可见的主题不出现在列表中。
