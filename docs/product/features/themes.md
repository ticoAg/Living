# 两种合集

- **旅程**：有起止日期，内容按时间排列，按天分段，画出路线，读作 [游记](/product/features/travelogue.md)。例："2026 秋 · 杭州三日"。
- **专题**：不受时间约束的精选，例："西湖四季""我的书法作品"。

合集原来叫「主题」。改名只改了界面上的叫法：`/themes`、`/t/:id` 这些地址、已有的内容、顺序和公开范围都没变，接口和表也沿用 themes 的名字。为什么旅程没有变成项目，见 [数据演进](/data/evolution.md#合集)。

# 内容

条目有四种，可以混排：

| 条目 | 是什么 | 本合集里能写的 |
|---|---|---|
| 照片 | 自己的一张照片 | 本合集里的说明，优先于照片笔记 |
| 记录 | 自己的一条 [记录](/product/features/entries.md)：标题、开头一段、照片 | 写在记录前面的话 |
| 文字段落 | 一段文字，空一行分段 | 段落本身 |
| 日期分段 | "第 N 天 · 10月3日 周六" | 这一天的说明 |

- 记录条目只是引用：记录的内容、照片和公开范围在记录本身改，合集里改不了。删除记录，它就从所有合集里消失。
- 一条记录可以放进几个合集；同一条记录也可以在一个合集里出现多次。
- 照片数、封面、路线和途经地点都算上记录里的照片。

# 创建

- 从空白开始，或从图库当前筛选、某个地点、一段日期范围的照片创建。
- 旅程：选定日期范围后，可以把这段时间自己的照片按天自动排好，并在每天第一张前插入"第 N 天"分段。
- 上传时也可以直接把新照片加入已有合集。

# 编辑

- 标题、副标题、导语（纯文本段落）、封面、起止日期（「取自内容」按照片和记录的日期填）、公开范围（公开 / 仅链接可见 / 仅自己）。
- 「添加照片」从自己的照片里挑；「添加记录」从自己的记录里挑，可以按标题和正文里的字、日期范围找，草稿和已归档的也在，标了出来。每一行的「+」也能在它后面插入照片、记录、文字段落或日期分段。
- 拖动或用上下按钮调整顺序；移除条目不会删除照片或记录。
- 合集公开或仅链接时，编辑器提醒有几张照片、几条记录读者看不到（仅自己可见、草稿、已归档），每一行也标出原因。
- 首次设为公开时记录发布时间。

# 列表

- `/themes`：所有公开合集，按更新时间倒序；`?mine=1` 显示自己的全部合集。
- 个人主页列出该用户的公开合集；[记录](/product/features/entries.md) 页和照片页列出收录它的公开合集（本人：全部）。

# 隐私

合集公开不会公开其中的私密照片和记录，见 [隐私](/product/features/privacy.md#合集)。
